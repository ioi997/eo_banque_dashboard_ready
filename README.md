# Néo-Banque – Dashboard IA

Projet complet prêt à déployer sur Render avec FastAPI + Streamlit.

## Démarrage rapide

- API : `uvicorn backend.main:app --reload`
- Dashboard : `streamlit run frontend/app.py`

## Déploiement Render
Connectez ce repo, configurez deux Web Services (API & Streamlit), c’est prêt.
